## About CampusHub-Community Portal
So I made this as I am always confused about which clubs are available to us in our university.
And therefore tried to make a community portal which let students explore all the clubs,events and community in their university.
I also added feature of Club Coordinator and Faculty mentor Dashboard, but it is still not interactive. 
It is just a HTML static webpages for now, later, with help of CSS we can add cards and design it well and also after adding javascript we can make interactive and responsive.

## Functional Requirements
### Student Module

* Student can access the landing page.
* Student can log in to the portal.
* Student can view the student dashboard.
* Student can explore available clubs.
* Student can view detailed information about a club.
* Student can browse upcoming campus events.
* Student can view complete event details.
* Student can register for an event using the registration form.
* Student can explore interest-based communities.
* Student can join a community.
* Student can view university announcements.


### Club Coordinator Module

* Coordinator can access the coordinator dashboard.
* Coordinator can view club information.
* Coordinator can manage club members.
* Coordinator can manage events.
* Coordinator can publish announcements.


### Faculty Mentor Module

* Faculty mentor can access the faculty dashboard.
* Faculty mentor can view club activities.
* Faculty mentor can monitor upcoming events.
* Faculty mentor can guide club coordinators.
* Faculty mentor can publish official notices.


### Navigation Requirements

* Users can navigate between pages using the navigation menu.
* Every page contains a consistent header and footer.
* Users can return to the landing page using the Logout/Home option.
